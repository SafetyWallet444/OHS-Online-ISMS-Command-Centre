# OHS Online ISMS Command Centre

Installable test application for implementing and operating an ISO/IEC 27001-aligned Information Security Management System.

## Test-data warning
This prototype stores records in the browser. Do not enter real credentials, confidential client records, medical information, security evidence or production secrets.
